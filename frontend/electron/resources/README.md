# Personal AI OS — Desktop Application Icons

This directory contains icon assets for packaging and running the Personal AI OS desktop application.

## Assets:
- `placeholder_icon.ico`: A binary placeholder Windows Icon (.ico) file generated for development testing.
- `icon.ico` (Future production asset): The final production custom brand icon (.ico containing 16x16, 32x32, 48x48, 64x64, 128x128, and 256x256 pixel layers) will be placed here prior to final installer packaging.

Application ID: `com.personalaios.desktop`
Application Name: `Personal AI OS`
